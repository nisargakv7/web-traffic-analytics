Web Traffic Analytics

Files:
- index.html: project page
- style.css: separate styling file

How to run:
1. Open this folder in VS Code.
2. Open index.html.
3. Right-click and choose Open with Live Server, or open index.html in a browser.

Note: This is a static HTML/CSS front-end demo. It does not perform real data processing, prediction, database operations, or map/geolocation queries. Replace placeholder values with your own verified results.
